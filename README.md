# AI 졸음 감지 시스템

웹캠으로 얼굴과 눈 상태를 인식하고, 일정 시간 이상 눈을 감으면 경고 문구와 알람 소리를 출력하는 Python 프로젝트입니다.

## 주요 기능

- 웹캠을 이용한 얼굴 인식
- 여러 사람의 얼굴 동시 감지
- 눈의 비율을 이용한 눈 감김 감지
- 졸음이 의심되는 상황에서 경고 문구와 알람 소리 출력

## 사용 기술

- Python
- OpenCV
- MediaPipe

## 설치 방법

```bash
pip install -r requirements.txt
```

## 실행 방법

```bash
python main.py
```

프로그램 실행 중 `q` 키를 누르면 종료됩니다.

## 참고 사항

눈의 비율을 이용해 졸음을 추정하는 학습용 프로젝트입니다. 실제 졸음 여부를 정확하게 판별하는 시스템은 아닙니다.
